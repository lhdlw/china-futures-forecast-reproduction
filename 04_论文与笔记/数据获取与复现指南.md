# 数据获取与复现指南

> 想复现这两篇论文，需要三类数据：①期货价格、②另类数据（文本/搜索）、③宏观经济数据。
> 下面按"从易到难、从免费到付费"整理。

---

## 一、期货价格数据（两篇都要）

### 免费 / 开源（推荐先试）
| 渠道 | 说明 |
|---|---|
| **AkShare**（Python，`pip install akshare`） | 完全免费开源，有期货日线接口，直接拿数据 |
| **Tushare Pro**（`pip install tushare`） | 注册拿 token，期货数据需一定积分，国内最常用 |
| **聚宽 JoinQuant / 米筐 RiceQuant / 优矿 Uqer** | 量化平台，有免费额度，API 取数据 |
| **交易所官网** | 大商所（玉米/大豆/鸡蛋/PVC）、郑商所、上期所（螺纹钢）可查历史行情 |
| **同花顺 / 东方财富** 网页 | 可手动导出，或用爬虫抓 |

### 学校/付费（数据最全、最规范）
- **Wind 万得**（高校金融实验室一般都有）
- **Choice 东方财富** / **同花顺 iFinD**
- **CSMAR 国泰安数据库**（学术论文常用，规范、可引用）

> 论文 2 用的是"国泰君安金融软件"（https://www.onlinedown.net/soft/115003.htm），本质就是这类行情软件，你用自己的 Wind/AkShare 一样能拿到等价数据。

## 二、另类数据（两篇的核心，也是难点）

### 论文 1：微博文本（最难，反爬严格）
1. **向作者要数据**（最省事）：论文 Data Availability 写明可合理索取，通讯作者邮箱 **zyrhbue@gmail.com**
2. **自己爬微博**：需要登录 cookie + selenium，反爬严格，微博 API 也限制多
3. **替代方案**：
   - 用公开的微博/中文语料数据集
   - 情感分析部分可先用现成词典（知网 HowNet、清华李军褒贬义词典、BosonNLP 情感词典、大连理工情感词典）复现 CDCSA
   - 涨跌分类可用 `Word2vec + TextRCNN`（PyTorch）复现

### 论文 2：百度指数 + 谷歌趋势
| 数据 | 获取方式 |
|---|---|
| **百度指数** | 官网 https://index.baidu.com 登录后手动查/导出；**无官方免费 API**，需用 selenium 爬（有反爬） |
| **谷歌趋势** | 官网 https://trends.google.com 可下载 CSV；Python 用 **pytrends** 库 |
| **关键词** | 论文表2（百度中文）、表3（谷歌英文）已列全，直接照抄 |

> 复现论文 2 时，ICPI 用 PCA（sklearn），传递熵 TE 用 PyInform 或 IDTxl 库，GWO 用 mealpy / scikit-opt 库。

## 四、复现建议路线（给新手）

**建议先复现论文 2（更简单、数据更好拿、开源）：**
1. 用 AkShare 拿 CSI300 + 5 个期货日线（2016-04 ~ 2021-04）
2. 用 pytrends 拿谷歌趋势关键词 CSV（百度指数手动导出或 selenium）
3. PCA 构建 ICPI（sklearn，照论文公式）
4. 先跑一个纯 **LSTM** 基线，再加 CNN-LSTM，最后加 GWO（scikit-opt 有现成 GWO）
5. 对比 MAE/RMSE/R²，看 ICPI 是否真的提升

**再进阶复现论文 1（文本部分工作量大）：**
1. 期货价格数据同上（大豆）
2. 宏观变量从统计局/USDA 拿
3. 微博文本：能拿到最好，拿不到就先复现"情感词典 + 度中心性"和"TextRCNN 涨跌分类"这两个模块
4. 逐步回归用 SPSS 或 Python（statsmodels 的逐步回归）
5. 单变量 LSTM + 多变量 LSTM + 误差倒数融合

> 经验之谈：复现的目的不是 100% 复刻数字，而是**跑通"数据→特征→模型→评价"这条管线**，然后换成自己的数据/改进方法。能跑通、能解释清楚每一步，就够组会展示了。

## 五、常用 Python 库清单
- 数据：`akshare` / `tushare` / `pandas`
- 搜索数据：`pytrends`（谷歌）
- 文本：`jieba`（分词）、`gensim`（Word2vec）、`snownlp`（情感）
- 降维/回归：`sklearn`（PCA）、`statsmodels`（逐步回归）
- 深度学习：`pytorch`（LSTM、TextRCNN、CNN）
- 优化：`scikit-opt`（GWO）、`mealpy`
- 传递熵：`pyinform` / `idtxl`
