# 论文1 阅读总结

> **标题**：Text-based soybean futures price forecasting: A two-stage deep learning approach
> **作者**：Wuyue An、Lin Wang（华中科技大学管理学院）、Yu-Rong Zeng（湖北经济学院信息工程学院）
> **期刊**：Journal of Forecasting, 2023, 42(2): 312–330. DOI: 10.1002/for.2909
> **数据可得性**：可向通讯作者合理索取（zyrhbue@gmail.com）

---

## 一、一句话概括

用**微博文本**（做情感分析 + 涨跌分类）提取 3 个文本特征，结合 10 个经济变量，用**逐步回归**筛选因子，最后用**两阶段 LSTM（TSH-LSTM）**预测中国大豆期货价格，证明"文本特征确实能提升预测精度"。

---

## 二、研究问题与动机

1. 传统大豆期货预测只依赖**历史价格/宏观数据**，忽略了社交媒体情绪等外部因素；
2. 现有情感分析**没考虑领域情感词**（很多词在期货语境下含义不同），也**只挖到文本表层特征**（情感），没挖到深层特征（涨跌）；
3. 本文用"情感词典 + 社会网络分析"改进情感分析，用 textRCNN 挖涨跌深层特征。

---

## 三、整体框架（四阶段）

```
阶段1  数据采集与预处理    数值数据(10) + 微博文本 → 清洗/编码/归一化
阶段2  文本特征挖掘        CDCSA情感分析 → 情感分
                           textRCNN涨跌分类 → 涨跌标签
阶段3  逐步回归筛选        13个候选因子 → 显著因子（SPSS）
阶段4  TSH-LSTM预测        单变量LSTM + 多变量LSTM → 误差倒数法融合
```

---

## 四、数据集详解

### 4.1 数值数据（10 个变量）

时间：**2011-07-29 ~ 2021-07-19**，有效 **795 天**。来源：国家统计局、全国农产品成本收益资料汇编、世界银行 + 交易所行情。

| 类别 | 变量 | 中文 | 主要来源 |
|---|---|---|---|
| 期货市场 | X1 持仓量 | 大豆期货持仓 | 交易所 |
| 期货市场 | X2 成交量 | 大豆期货成交 | 交易所 |
| 期货市场 | X4 美豆期货价 | CBOT美豆 | 世界银行/Wind |
| 大豆基本面 | X3 大豆现货价 | 现货价 | 国家统计局 |
| 大豆基本面 | X7 黄玉米期货收盘价 | 玉米C0 | 交易所 |
| 大豆基本面 | X8 黄玉米持仓量 | 玉米持仓 | 交易所 |
| 大豆基本面 | X9 食用油现货指数 | 食用油指数 | 国家统计局 |
| 经济环境 | X5 汇率 | 美元/人民币 | 世界银行/央行 |
| 经济环境 | X6 WTI原油现货价 | WTI现货 | 世界银行/EIA |
| 经济环境 | X10 WTI原油期货价 | WTI期货 | EIA |

> 训练/测试划分：前 **85%** 训练、后 **15%** 测试；训练集里再分 15% 作验证集。

### 4.2 文本数据（微博 + 粮油网站）

- **来源**：微博上关于大豆期货的帖子 + "China Food"（粮油类网站）相关信息；
- **采集**：Python 3.7 网络爬虫，2011–2021 共约 10 年；
- **最终产出 3 个文本特征**：`Sentimenttrend`（词典情感分）、`Imsentimenttrend`（CDCSA改进情感分）、`Labeltrend`（涨跌标签）。

## 五、文本数据处理详解（核心，重点看这里）

文本是**非结构化**的（一句话、一段字），模型算不了。所以要分**两条路**把它变成**数字**：

```
微博文本（"大豆今天大涨了！"）
        │
        ├─ 路1：情感分析 CDCSA ──→ 每天一个"情感分数"（正=看多，负=看空）
        │                         → 产出 X11 词典情感分、X12 CDCSA情感分
        │
        └─ 路2：涨跌分类 textRCNN ──→ 每条微博打"涨/跌"标签
                                     → 产出 X13 涨跌标签
```

### 5.1 路1：CDCSA 情感分析（改进情感分怎么算）

CDCSA = 情感词典法 + 社会网络分析的度中心性 + 并列/转折约束。分三步：

**第 1 步：建"领域情感词典"**
把两个通用词典合并，并补充网络新词：
- **清华李军褒贬义词典**（通用正/负情感词）
- **知网 HowNet 情感词典**（通用正/负情感词）
- 用 **PMI（点互信息）** 识别并判定网络新词的情感倾向（比如"起飞""割韭菜"这类词典里没有、但网上常用的词）

> 为什么要"领域"词典？因为通用词典分不清期货语境——比如"暴跌"在通用词典是中性，但在期货语境是明确的负面词。

**第 2 步：算"度中心性"，并识别并列/转折关系**
- **度中心性**：把情感词当节点，两个词若在同一条微博里**共现**就连一条边，构成一个词网络。某词的度中心性 = 它连了几个词 / (总词数-1)。**连得越多，说明这个词越"核心"、情感倾向越强**（式1）。
- **并列关系**（"大涨**和**利好"）：两个词情感倾向**相同**，互相加强；
- **转折关系**（"涨了**但是**回落"）：两个词情感倾向**相反**，要反转。

**第 3 步：加权求和得到每天的情感分**
把当天所有微博里的情感词按"极性 × 度中心性"，再用并列/转折关系修正正负号，累加 → 得到**当天整体情感分**。

> 结果：CDCSA 的 Accuracy/Precision/Recall/F1 = **0.8 / 0.83 / 0.81 / 0.82**，比纯词典法（0.68）高，说明"度中心性 + 并列转折"确实有用。

### 5.2 路2：textRCNN 涨跌分类（深层特征怎么挖）

目标是：**判断"某条微博的内容是在说涨还是跌"**。做法是给它打标签再训练分类器。

**打标签（式5）**：用价格自己定义对错——
- 当天价 > 昨天价 → 标签 **+1**（涨）
- 当天价 < 昨天价 → 标签 **-1**（跌）

**textRCNN 模型**（"文本循环卷积神经网络"）：
1. **Word2vec 词嵌入**：把每个词变成一个向量（把"大涨"变成一串数字）；
2. **BiLSTM**：从正反两个方向读句子，学上下文（"涨"前面是"不"还是"大"，意思完全不同）；
3. **拼接**：每个词的左上下文 + 词本身 + 右上下文 拼成一个向量（式2–4）；
4. **Max pooling**：从所有词向量里取最强的特征；
5. **Softmax 分类**：输出"涨/跌"。

对比了 Transformer、TextCNN、DPCNN、TextRNN_Att 等模型，**textRCNN 10 折交叉验证准确率最高（62.5%）**。

> 所以 X13 `Labeltrend` 就是"每天被判定为涨的微博比例/倾向"，它反映了**文本里隐含的涨跌信号**。

### 5.3 三个文本特征小结

| 特征 | 含义 | 怎么来的 |
|---|---|---|
| X11 Sentimenttrend | 词典法情感分 | 清华+HowNet 词典，正负词数比 |
| X12 Imsentimenttrend | CDCSA 改进情感分 | 词典 + 度中心性 + 并列转折 |
| X13 Labeltrend | 涨跌标签特征 | textRCNN 分类（Word2vec+BiLSTM） |

---

## 六、特征筛选：逐步回归（SPSS）

把 13 个候选因子（10 数值 + 3 文本）做**逐步回归**：逐个引入，F 检验/t 检验显著的留下，不显著的剔除。

**结果**：最终模型 **只剔除了 X9（食用油现货指数）**，其余 12 个全保留，**调整 R² = 0.922**。说明这 12 个因子（含 3 个文本特征）对大豆期货价格解释力很强。

---

## 七、预测模型：TSH-LSTM（两阶段）

```
阶段A 单变量 LSTM：只输入历史价格 → 预测 S(t)   （短期准，长期差）
阶段B 多变量 LSTM：输入筛选后的12个因子 → 预测 M(t)（长期稳）
        ↓ 误差倒数法加权融合
  最终预测 = w1·S(t) + w2·M(t)  （误差小的权重更大）
```

- 最优序列长度 **Seq_length = 7**（约一周）；
- 环境：Anaconda + Python 3.7 + PyTorch 1.13.1；
- 超参用网格搜索。

---

## 八、结果

| 模型 | MAPE | RMSE | MAE |
|---|---|---|---|
| **TSH-LSTM** | **5.891%** | **0.094** | **0.068** |
| 单变量 LSTM | 8.716% | 0.102 | 0.084 |
| 多变量 LSTM | 26.531% | 0.217 | 0.182 |
| XGBoost | 59.862% | 0.314 | 0.276 |

TSH-LSTM 全面最优，证明"文本特征 + 两阶段融合"有效。

---

## 九、创新点

1. **CDCSA 情感分析方法**：把"度中心性（社会网络分析）"引入情感词典法，并识别**并列/转折**关系，弥补了通用词典在期货领域不准的缺陷（准确率 0.68→0.8）；
2. **textRCNN 挖深层涨跌特征**：不只做表层情感，还用"价格涨跌当标签"训练深度模型，从文本里挖出涨跌信号；
3. **两阶段 TSH-LSTM**：单变量 + 多变量 LSTM，用**误差倒数法**融合，兼顾短期精度和长期稳健；
4. **经济计量 + 深度学习结合**：先用逐步回归筛选因子（可解释），再喂给深度学习（高精度）。

---

## 十、局限与可复现性

1. **只在大豆期货一个品种上验证**，推广性未知；
2. **微博文本拿不到**是最大复现障碍：论文没公开语料，历史微博（尤其 2011–2015）几乎爬不到，只能发邮件向作者索取；
3. 深度学习仍是"黑箱"，缺可解释性；未来方向：ITD 分解、Granger 因果检验、SHAP/LIME。
