# 百度指数数据采集说明

百度指数（https://index.baidu.com）是论文 2 的核心另类数据源之一。**它没有公开的免费 API，且数据接口加密 + 需要登录**，全自动爬取既不稳定也不合规。因此这里给两条路：**手动导出（推荐，最可靠）** 和 **Selenium 半自动（需要你自己登录）**。

---

## 一、论文用的关键词（Table 2）

论文选的是**能预测中国 CPI 的宏观词**，不是某个具体期货的词。完整清单如下（中文 / 拼音 / 英文）：

| 词性 | 关键词（中文） | 拼音 | 英文含义 |
|---|---|---|---|
| 名词 | 价 | jia | Price 1 |
| 名词 | 价格 | jiage | Price 2 |
| 名词 | 物价 | wujia | Price 3 |
| 正向情绪 | 暴跌 | baodie | Plunge |
| 正向情绪 | 大涨 | dazhang | Large rise |
| 正向情绪 | 下跌 | xiadie | Drop |
| 正向情绪 | 上涨 | shangzhang | Rise |
| 动词 | 降价 | jiangjia | Decrease in price |
| 动词 | 涨价 | zhangjia | Rise in price |
| 动词 | 价格上涨 | jiageshangzhang | Price increase |

> 论文最终用 PCA 筛选出 9 个词（Table 4 + 式5）：
> **价(jia)、降价(jiangjia)、价格下降(jiagexiajiang)、价格上涨(jiageshangzhang)、上涨(shangzhang)、下跌(xiadie)、涨价(zhangjia)、价格(jiage)、涨价+降价(zhangjia,jiangjia)**

---

## 二、方法 1：手动导出（推荐）

1. 打开 https://index.baidu.com ，登录百度账号（扫码即可）
2. 搜索框输入关键词，比如「**涨价**」
3. 时间范围设为 **2016-04-01 ～ 2021-04-30**（"自定义"→"全部时间"里选）
4. 页面右侧/右上角有 **「导出」/「下载」按钮**，导出为 Excel 或 CSV
5. 对上面 9 个关键词逐个重复，存到 `data/baidu_index/` 目录

> 提示：百度指数免费版对单次导出有时间窗口限制，超长区间会要求分多段导出，分段后再拼起来即可（论文自己也是分多次下载的）。

## 三、方法 2：Selenium 半自动（可选，需你自己登录）

下面的脚本会：打开浏览器 → 你手动扫码登录一次 → 脚本按关键词列表逐个搜索并停留，方便你点导出。
（因为百度指数数据是加密渲染的，脚本只帮你"导航到对应页面"，导出动作仍建议手动点按钮，最稳妥。）

```python
# 依赖：pip install selenium
# 还需下载与 Chrome 版本匹配的 chromedriver 放进 PATH
from selenium import webdriver
from selenium.webdriver.common.by import By
import time, urllib.parse

KEYWORDS = ["价", "价格", "物价", "暴跌", "大涨", "下跌", "上涨", "降价", "涨价", "价格上涨"]

driver = webdriver.Chrome()
driver.get("https://index.baidu.com/v2/main/index.html")

input(">>> 请在打开的浏览器里扫码登录百度，登录完成后回车继续...")

for kw in KEYWORDS:
    url = "https://index.baidu.com/v2/main/index.html#/trend/" + urllib.parse.quote(kw) + "?words=" + urllib.parse.quote(kw)
    driver.get(url)
    time.sleep(8)          # 等页面加载
    print("当前关键词：", kw, " -> 请在页面点「导出」下载数据")
    time.sleep(2)

driver.quit()
```

> 若嫌 Selenium 麻烦，**直接用手动导出（方法 1）最省心**，数据质量一样。
