# 代码说明

8 个脚本按**论文流程顺序**编号如下，逐个运行即可完整复现。

## 执行顺序（管线）

| 步骤 | 脚本 | 作用 | 对应论文 |
|---|---|---|---|
| 1 | `fetch_futures.py` | 用 AkShare 抓 6 个期货品种日线（含玉米/大豆/PVC/鸡蛋/螺纹钢） | §2.1 |
| 2 | `fetch_google_trends.py` | 抓谷歌趋势英文关键词（含跨段重标定） | §2.2 |
| 3 | `organize_baidu.py` | 整理百度指数（手动导出的 Excel → CSV 宽表） | §2.2 |
| 4 | `reproduce_features.py` | 9 关键词 → 对数 → 时滞 → z-score → PCA → 式(4) → **ICPI** | §3.1 |
| 5 | `reproduce_te.py` | KSG 估计器算**传递熵 TE**（窗口60/步长1） | §3.2 |
| 6 | `reproduce_model.py` | **GWO-CNN-LSTM** 预测，对比 [仅价格] vs [价格+ICPI+TE] | §3.3–3.4 |
| 7 | `ablation.py` | **消融实验**（单独 ICPI / 单独 TE，定位拖后腿特征） | 补充实验 |
| 8 | `reproduce_corn_paperdata.py` | 数据截到 2020-09-30，**对齐论文玉米数据期**重跑 | 补充实验 |

## 依赖库

```bash
pip install pandas numpy scikit-learn torch pytrends akshare
```

## 运行注意

1. **科学上网**：脚本 2（谷歌趋势）必须开代理，脚本会自动读 Windows 系统代理。
2. **KMP 冲突**：跑含 torch 的脚本（4–8）前先 `set KMP_DUPLICATE_LIB_OK=TRUE`（Windows 上 numpy/MKL 与 torch 的 libiomp5md.dll 冲突）。
3. **路径**：脚本内相对路径按 `data/` 书写，请确保脚本同级存在名为 `data` 的文件夹（本成果包中对应 `03_数据`，重跑前改名即可）。
4. **只跑玉米**：`python reproduce_model.py C0`；消融实验：`python ablation.py`。
